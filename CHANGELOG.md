# Release notes

## 0.1.0

- Standalone three-rotor Enigma M3 for 8 MB ESP32-S3 Cardputers.
- Rotors I–VIII, wide reflectors B and C, ring settings, up to ten plugboard pairs,
  naval turnover, and middle-rotor double-stepping.
- Landscape keyboard interface with live rotor windows, reversible editing,
  configuration, and help.
- USB JSON protocol for streaming cipher input, device status, and test automation.
- Verified on Cardputer-ADV with independent historical vectors and a scripted
  hardware regression suite.
